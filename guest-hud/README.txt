BEBOP HOOK ARENA — PLAYER KIT

1. Extract the entire ZIP into a normal folder.
2. Sign in to Steam. Deadlock must already be installed.
3. Set the current server IP/hostname in server.txt.
4. Run Start HUD.cmd. It installs the map/HUD and launches Deadlock.
5. Keep the launcher window open while playing.

Portable Node.js is included. No separate Node installation is needed.
If asked for the game folder, enter the path to Deadlock/game/citadel.
The installer backs up gameinfo.gi before adding its mount.
Only launch one copy of the relay (local TCP 4320).
The server must provide the game on port 27067 and HUD on TCP 4321.
This archived version still has an unresolved intermittent server crash.
